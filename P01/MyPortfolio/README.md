# Practical 01: Project Folder & Terminal Navigation

## Overview
This practical covers setting up a dedicated project workspace using essential command-line terminal commands and establishing standard web project folder conventions.

## Terminal Commands Used
1. `pwd` - Print current working directory
2. `mkdir -p P01/MyPortfolio` - Create project directory tree
3. `cd P01/MyPortfolio` - Navigate into the newly created folder
4. `touch index.html style.css README.md` - Generate project starter files
5. `ls -la` - Verify file generation and permissions

## Project Files
- `index.html`: Base HTML5 structure
- `style.css`: Initial CSS styling sheet
- `README.md`: Practical documentation and command logs

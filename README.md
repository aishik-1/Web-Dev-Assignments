# Web Development Practicals & Assignments (P01 - P13)

This repository contains my complete collection of web development practical assignments covering the fundamentals of terminal commands, Git version control, semantic HTML5, modern CSS styling systems, Flexbox, and CSS Grid layout architectures.

---

## Curriculum Overview

### Module 1: Terminal, Git & GitHub (P1–P4)
* **[P01](./P01/MyPortfolio/)**: Project folder initialization, directory tree setup, and terminal navigation (`pwd`, `cd`, `mkdir`, `touch`).
* **[P02](./P02/Portfolio/)**: Portfolio repository setup with an initial commit, staging changes, and commit tracking.
* **[P03](./P03/FeatureBranch/)**: Feature-branch Git workflow (`feature/about-page`) demonstrating branch isolation and merge workflows.
* **[P04](./P04/)**: GitHub documentation standards, release tagging (`v1.0.0`), and repository structure.

### Module 2: HTML & CSS Foundations (P5–P9)
* **[P05](./P05/)**: Semantic bio page featuring `<header>`, `<main>`, `<section>`, `<footer>`, and typography styling.
* **[P06](./P06/)**: Full developer portfolio page structure built using semantic HTML5 elements and component cards.
* **[P07](./P07/)**: CSS Design tokens and typographic scale architecture implemented via `:root` CSS custom properties.
* **[P08](./P08/)**: CSS Positioning practical featuring a sticky navigation bar (`position: sticky`) and hover card overlays (`position: relative` / `position: absolute`).
* **[P09](./P09/)**: Responsive navigation header and fluid card grid built with CSS Flexbox and media breakpoints.

### Module 3: CSS Layout Systems (P10–P13)
* **[P10](./P10/)**: Advanced Flexbox application featuring proportional spacing (`flex-grow`, `flex-shrink`, `flex-basis`), custom header, and multi-tier footer.
* **[P11](./P11/)**: Newspaper-style editorial multi-column layout using asymmetric CSS Grid tracks (`2fr 1fr 1fr`) and spanning elements.
* **[P12](./P12/)**: Portfolio projects showcase grid utilizing advanced CSS Grid features (`repeat(auto-fit, minmax(...))`, column spans, row extensions).
* **[P13](./P13/)**: Comprehensive layout synthesis and decision guide: choosing between Flexbox (1D) and CSS Grid (2D) for real-world web layouts.

## Running & Previewing Locally

Each practical folder is self-contained. To inspect any practical:
1. Clone this repository:
   ```bash
   git clone https://github.com/aishik-1/Web-Dev-Assignments-.git
   ```
2. Navigate into the desired assignment folder:
   ```bash
   cd Web-Dev-Assignments-/P13
   ```
3. Open `index.html` in any modern web browser or start a local server:
   ```bash
   python3 -m http.server 8000
   ```

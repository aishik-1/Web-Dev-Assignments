## Git Workflow & Tagging
This repository leverages semantic release tagging to mark major milestones:
- Version `v1.0.0`: Initial release marking completion of Module 1 (Terminal, Git, and Repository Foundation).
- Feature branching: All new pages are developed in isolated topic branches (e.g., `feature/about-page`) before code review and fast-forward/squash merging.

```bash
# Tag creation command
git tag -a v1.0.0 -m "Release version 1.0.0: Terminal, Git and Repository Foundation"

# Push tag to GitHub
git push origin v1.0.0
```
